# 运行动力示教

本指南用于已完成本套设备身份、方向和零位核对的操作人员，完成单对或双对示教及正常退出。首次部署先完成[离线教程](../tutorials/first-offline-run.md)。命令从仓库根目录执行。

## 1. 核对连接与配对

退出占用同一机械臂串口的扫描、RViz、MoveIt 或独立重力补偿会话。检查当前 USB 设备：

```bash
ls -l /dev/serial/by-id/
bash A6-Y-G/scripts/run_arm_scan.bash --cli --arms all --passes 5
```

第二条命令只发状态查询，不使能、不失能、不发送运动目标。双对示教应看到四臂各 7 台电机响应；单对操作可以把 `all` 改为实际使用的两个角色，例如 `teaching_left motion_left`。若反馈显示电机已使能，先按设备操作流程托住并处理残留输出，不直接启动接管。

USB 身份不匹配时按[更换 USB2CAN](replace-usb-can-adapter.md)处理，不用 `ttyACM0` 等临时编号猜测左右臂。

## 2. 打开窗口并选择真机模式

```bash
bash A6-Y-G/scripts/run_arm_teaching.bash
```

1. 保持默认同侧配对，或从下拉框选择交叉配对；取消一组即为 1 对 1。同一机械臂不能重复出现在两组中。
2. 选择 **“真机动力示教”**。
3. 对齐示教与运动臂的初始姿态，留出跟随和回零的路径空间。启动不先回零，六轴会趋向示教臂的绝对关节角度。
4. 点击 **“启动：直接跟随示教臂”**，等待所选臂的状态确认进入跟随。身份、反馈或模式核验失败时，按窗口给出的具体臂和原因排查。

启动时运动夹爪先保持实测开度，再限速进入示教开度；六轴保留 1.2 秒软启动。原生控制与目标发布配置频率见[参数参考](../reference/runtime-and-configuration.md#动力示教参数)。

## 3. 操作夹爪并查看反馈

缓慢开合示教夹爪，检查运动夹爪按百分比跟随。空载时示教 J7 有轻微速度阻尼；运动端检测到接触后保持捕获的位置目标，并向示教端反馈阻力。张开示教夹爪可撤力并释放保持。

反馈基于电机估计力矩，运动端采用 POS_VEL 位置保持。**2 N·m 是示教电机反馈与阻尼的总上限**，不是固定反馈值或物体夹持力上限。触发情况用[夹爪日志](inspect-teaching-logs.md)确认。

## 4. 正常停止

点击 **“停止示教 · 回零并失能”**；关窗或第一次 Ctrl+C 也请求正常退出。

- 先停止跟随；各已接管臂的 J1～J6 使用原生位置模式回零。
- 参与臂的夹爪保持停止／回零接管时的实测开度，不把 J7 数值零作为夹爪回零目标。
- 到位后七轴失能并核验反馈，夹持力随之释放。等待窗口显示会话结束及失能确认，再关闭设备。

回零没有跨臂、桌面或线缆碰撞规划。失败时窗口保留原因，可处理后重试；不要把强制结束进程当作已完成失能。

需要跳过回零时，先托住全部参与机械臂并接住夹持物，再点击 **“已托住全部 · 立即失能”**。此操作会撤去力矩支撑；软件失能不等于断电。缺失反馈时界面无法确认失能成功。

## 5. 保存本次结果

等待报告生成后点击 **“导出诊断包”**。修改源码或配置后，关闭旧窗口，再运行同一启动命令；运行中的节点不会自动加载新参数。
