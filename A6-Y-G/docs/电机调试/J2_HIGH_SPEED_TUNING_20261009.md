## 测试姿态与速度含义

沿用操作者此前确认的 J2 扫掠范围：固定其他五轴，J2 从约 0°到约 103°的范围无碰撞，现场可就地断电。本轮仅使用 **0–90°**，夹爪全程只读、失能。旧姿态与确认记录保存在 [operator_anchor.json](../../validation/j2_highspeed/20261009_90dps/operator_anchor.json)。

| 关节 | 测试保持位置，模型 rad |
| --- | ---: |
| J1 | 0.020027 |
| J2 | 从 0 运动至 π/2，再返回 0 |
| J3 | 0.558289 |
| J4 | −0.567826 |
| J5 | 0.058556 |
| J6 | −0.000191 |

每轮捕获当前实测姿态，使能并稳定保持，然后以计划峰值不超过 2.5°/s 回到上述姿态。完成回位后仅 J2 运动，其余五轴保持误差检查仍为 2°。J2 原始零位约 −0.004005 rad，在原有 ±2°容差内；保持目标取名义零位，没有修改 offset。

90°/s 是五次平滑曲线的**峰值**，90°单程为 **1.875 s**，计划峰值加速度约 2.58 rad/s²。不是从起点直接以 90°/s 匀速转满一秒。此结果只覆盖本次姿态、负载和轨迹，不等同于所有姿态、六轴同时运动或 VR 遥操作均已通过。

## 为什么不能只提高位置增益

最初只调整 `KP_APR`：1250、1600、2000 分档通过较低速度试验，但在原速度环参数下，`KP_APR=2500`、75°/s 到位时出现明显振荡。操作者报告短暂抖动或异响。这轮虽然完成往返、最后一秒也稳定，仍不作为通过的选值。

到位后位置参考已经固定，原参数下编码器和反馈力矩仍反复振荡。随后按单变量对照调整速度环：先提高比例，再减小积分，保持同样的姿态和速度比较。比例从原值的 110%、120%逐步试到 135%、160%、190%；积分从原值的 100%试到 80%。降低积分 20%这一小步的改善不明显；提高速度环比例后，多组相同位置增益的试验显示端点波动减小。中间位置增益 2250、速度比例 120%的一轮现场报告抖动加重，已明确排除。

这支持“位置环与速度环需要匹配”的判断。本轮实际调整的是 **`KP_ASR`、`KI_ASR`**，不是把 MIT `kd` 或 `Deta` 改大。原生位置速度模式使用位置、速度、电流串级环，不能把它当作 MIT 的直接 PD 力矩控制；手册对阻尼因子的说明涉及调试助手自动计算参数，不能据此断言单写 `Deta` 就会重算实际增益。[厂家中文手册，第 5–6、13–14 页](https://damiao.enactic.ai/en/assets/files/dm-j4340p-2ec-v1.0-zh-8460bcc658b2f0e8830a63d4dffc18df.pdf)。

## 判定与流程修正

原先标准包括完整往返并失能、峰值速度为目标的 95%–105%、计划误差 ≤3°、保持最后一秒跨度与平均误差绝对值 ≤0.2°、端点超越 ≤0.5°。发现短时振荡后，补充了**计划到位后前 1.5 s 跨度 ≤0.2°**、去回程分别检查峰值和现场观察通过。这是发现问题后补充的诊断标准，不冒充原先预注册的条件。

`report.json` 的 `passed` 只表示流程完整且失能；`comparison.json` 的 `performance_target_met` 表示数值条件通过，`accepted` 还要求该轮有明确的现场良好反馈。未单独询问的中间轮次保留 `operator_acceptable=null`，不推断操作者的感受。最终两轮均满足数值与现场判定，见 [selection.json](../../validation/j2_highspeed/20261009_90dps/selection.json)及[现场观察](../../validation/j2_highspeed/20261009_90dps/operator_observations.json)。

五次扫掠前未完成分别是：准备保持等待超时、CAPTURE 请求被拒绝、初始 J5 姿态被新加的回位范围限制拒绝、单帧初始速度检查失败、PREPARE 请求被拒绝。均记录并确认失能，未把它们当作已完成的运动试验。针对这些证据作了以下修正：

- 实读 J4/J5/J6 的 `VMAX=50`，旧默认解码量程为 30；在三份 A5 电机 YAML 为它们补上 `protocol_vmax: 50.0`。只修正主机编码/解码量程，没有写电机 `VMAX`，也没有提高运动限速。
- 手腕原生速度估计会在编码器几乎不变时跳过 0.03 rad/s 稳定阈值。外层到位等待改用 0.15 s 编码器窗口、跨度 <0.1°与平均变化速率 <0.03 rad/s；控制器自己的 PREPARE/ARM/CAPTURE 原始速度检查仍保留。
- 对反馈有效、状态仍匹配的明确准备请求拒绝，最多等待重试 5 s；通信故障、FAULT 和运动过程中异常不自动重试。
- 撤销试验工具新加的“初始姿态距记录值必须在 2°内”限制，恢复旧 J2 流程：先捕获有效当前位置，再慢速回到操作者确认过的旧姿态。回位后的其他五轴 2°保持检查仍保留。

另有一次启动请求因自动权限审核超时未执行，按工具允许重试后成功；它不计入 25 次实机启动。以上修正均未移除反馈超时、跟踪误差、位置范围、速度或力矩停止条件。

## 测试配置与日常 VR 的区别

新增 [J2 高速测试工具](../../tools/test_j2_highspeed.py)和[启动脚本](../../scripts/run_j2_highspeed_test.bash)。它复用 J1 已验证的有界前瞻轨迹生成，在 125 Hz 控制器下测试原生位置环，不使用 Quest、IK 或力控。

90°/s 档仅在生成的试验快照中设置 J2 指令限速 1.65 rad/s、反馈速度检查 1.90 rad/s；参考加速度仍为 3 rad/s²，跟踪误差门限仍为 0.05 rad，反馈有效期仍为 50 ms。六轴反馈力矩停止门限为 10/20/20/3/4/4 N·m。较低速度档同步降低 J2 速度上限。

**原生增益会作用于当前通电的 J2；日常 VR 的速度上限没有随本轮测试提高。** 三份电机 YAML 的变化仅为 J4–J6 反馈量程修正，旧低速试验入口不变。82 项相关离线测试通过，最新完整 mock 流程通过；mock 峰值约 89.51°/s，只验证软件流程，不代表动力学性能。

## 读取、恢复参数与复测

在项目根目录、退出占用 CAN 的程序后读取：

```bash
cd /home/alce/Code/A6-Y-G
source scripts/environment.bash
a6y_load_install
ros2 run a6_y_ros2_control read_motor_params.py --joints joint2 \
  --params CTRL_MODE,KP_APR,KI_APR,KP_ASR,KI_ASR,Deta,V_BW,ACC,DEC
```

掉电后先读回，需要恢复本轮选值时，在电机失能状态临时写入：

```bash
ros2 run a6_y_ros2_control write_motor_params_temp.py --joints joint2 \
  --set KP_APR=2500 --set KP_ASR=0.007296 --set KI_ASR=0.0016 --yes
```

这条命令不使能、不保存 Flash，也不需要重新编译。若要回退**本轮开始前的三个增益**：

```bash
ros2 run a6_y_ros2_control write_motor_params_temp.py --joints joint2 \
  --set KP_APR=250 --set KP_ASR=0.00384 --set KI_ASR=0.002 --yes
```

上述回退命令不改变模式。`KI_APR=0`、`Deta=4`等本轮未改参数以实际读回为准。保存 Flash 是另外的操作，本轮未执行，见 [电机参数工具](MOTOR_PARAMETERS.md)。

仅在本次已确认的安装、姿态和完整扫掠范围内复测：

```bash
bash scripts/run_j2_highspeed_test.bash --mode real \
  --anchor-json validation/j2_highspeed/20261009_90dps/operator_anchor.json \
  --degrees 90 --peak-speed-deg-s 90
```

命令会先使能并慢速回到旧 J2 初始姿态，再执行往返；不会把任意新姿态当作已验证姿态。测试工具本身不写原生增益，运行前应确认读回与本轮选值一致。
