# J4 速度反馈重新标定（2026-10-10）

**已完成只读量程核对、静态零点测量和历史双向轨迹标定。** 当前 `VMAX=50 rad/s` 与驱动配置匹配；保留倍率 **1.0**。J4 模型坐标下存在约 **+0.700°/s** 的反馈零偏，与半个速度量化格一致。离线扣除该值后，11 次完整 90°往返、22 个方向的速度积分相对编码器行程的最大误差从 **26.81% 降至 1.04%**。

本次标定文件用于离线分析，**没有加载到在线驱动或速度保护链**。它验证的是以本机编码器为参照的长窗口一致性，不是外部测量下的绝对速度精度，也不证明瞬时速度峰值或 20°/s 运动已经合格。没有新增运动、写电机参数或保存 Flash。

[标定文件](../../validation/j4_speed_calibration/20261010/calibration.json)明确记录 `usage=offline_analysis_only`、`applied_to_runtime=false`。在本文验证的量程、方向及单位下：

```text
v_calibrated = v_native_model - 0.01221001221001221  # rad/s
```

若从原始 12 位速度码 `N` 计算，则等价于 `v_calibrated=(2047-N)*100/4095`。这里的 `v_native_model` 是已经应用 J4 方向映射的速度；电机原始坐标的零点符号相反，不能直接照搬模型坐标的减法。不能把此系数套用到其他轴或其他 VMAX。

厂家手册说明速度反馈采用 12 位线性映射，见 [DM-J4310-2EC V1.1 手册第 6～7 页](https://damiao.enactic.ai/assets/files/dm-j4310-2ec-v1.1-zh-5d089e0b013d8e2fc203c5b670008a66.pdf)。本仓库 Python/C++ 解码均使用 `N/4095*100-50`；零码 2047 对应电机坐标 `−0.012210 rad/s`，经 J4 反向映射成为正值。实测支持“零点量化偏置”的解释，但没有据此声称已审计电机内部固件的量化实现。

## 实测与交叉验证

在七电机失能状态下完成 8 秒只读 CAN 采样，各电机各 483 帧。J4 速度码分布为 `2046:35`、`2047:414`、`2048:34`；位置跨度约一个位置量化格，即 `0.021857°`。按接收时间加权的原生均速为 **+0.701035°/s**，离线扣零后为 **+0.001452°/s**。早期快速检查使用帧均值约 +0.702°/s；正式报告使用时间加权值。原始帧见 [static_raw.jsonl](../../validation/j4_speed_calibration/20261010/static_raw.jsonl)。

动态交叉验证使用既有 11 次完整、确认失能、90°往返数据，涵盖计划峰值 5°/s 和 10°/s、不同速度环参数。使用控制器同拍的 `actual`、`actual_velocity` 和 `t_ns`，对每个运动方向做梯形积分，再与编码器净位移比较。未完成的试验及 10°小行程不参与倍率验证；排除清单与每轮结果均保存在报告中。零偏取静态量化格确定值，倍率固定为 1，没有逐轮拟合系数来压低误差。

## 时间对齐与高速故障

将积分时钟从控制器时钟改为回调接收时钟，22 段中最大积分差仅约 **0.075°**，无法解释原来的 12°～24°累计偏移。

为避免把瞬时速度与平滑差分直接比较，另将两路都放到相同的 24/50/100/200 ms 窗口。最后一轮 10°/s 的 50 ms 窗口，扣零后的原生均速与编码器差分的 RMS 差为去程/回程约 **0.574/0.676°/s**；离线搜索 ±40 ms 对齐后，最佳偏移约 +4/+5 ms，RMS 差约 **0.298/0.300°/s**。偏移搜索分辨率 1 ms，但原始采样约 8 ms，不能将拟合结果视作具有 1 ms 精度的硬件延迟测量；没有将该偏移加载到在线状态。

既有四次 20°/s 故障锁存速度，离线扣零后的对照如下。历史故障拍没有完整位置遥测，数值来自随后 `command_diagnostics` 的锁存状态，不能补造同步峰值证据。

| 位置比例 / 速度比例 / ACC | 原生 rad/s | 离线扣零后 rad/s | 相对原 0.5 rad/s 门限 |
| --- | ---: | ---: | --- |
| 54 / 220% / 2 | 0.549451 | 0.537241 | 仍超过 |
| 68 / 220% / 2 | 0.525031 | 0.512821 | 仍超过 |
| 68 / 220% / 3 | 0.500611 | 0.488400 | 该锁存值降至门限以下 |
| 68 / 180% / 2 | 0.525031 | 0.512821 | 仍超过 |

因此不能把四次停止全部解释成零偏造成的误报。图中也可见扣零只平移曲线，短时波动仍在。下一轮动态诊断应使用已增加的首个 `fault_state` 日志核对同拍位置、速度、参考和反馈年龄；本次没有继续提速或改写原失败判定。
