## 姿态与范围

操作者提供两组原始电机位置，并明确确认：其他关节固定为第一组姿态时，J2 从约 0°到第二组的约 103°，整个扫掠范围无碰撞，能够就地停机。两组原始数值保存在 [operator_poses.json](../../validation/j2_tuning/20261009_122705/operator_poses.json)。第二组的 J3、J4 也不同，因此没有把第二组整臂姿态当成测试终点。

按当前电机 YAML 的符号、比例与 offset 转换后，保持目标为：

第一组 J2 原始值为 -0.004005 rad（约 -0.23°），在已有 ±2°零位容差内。本轮命令回到名义零位 0 rad，没有改 offset 或反馈读数。J2 测试上界为 1.801137 rad。自动回位必须先使能电机，因此程序先保持实测当前位置，再以计划峰值不超过 2.5°/s 的五次平滑轨迹回位。

试验开始的只读反馈显示 J3 约 0.3°，尚未处于第一组的约 32°，所以每轮均实际核对回位结果。运动过程五个固定关节允许的实验偏差上限为 2°；保留控制器原来的反馈、速度、跟踪误差和通信检查。电机反馈力矩额外按项目已有六轴限值 10/20/20/3/4/4 N·m 检查。

## 方法

使用 [test_j2_position.py](../../tools/test_j2_position.py) 和 [启动脚本](../../scripts/run_j2_position_test.bash)，专用 `/j2_test` 控制器，125 Hz 原生 `pos_vel` 位置模式。真实硬件域为 0，模拟域为 87；夹爪不使能。无 VR 或逆运动学输入。跟踪误差门限仍为 0.05 rad，参考速度上限 1 rad/s、加速度上限 3 rad/s²，保留跟踪减速器。

每轮：当前位置保持 → 回到第一组 → 移至 J2 测试窗口起点 → J2 去程/保持/回程/保持 → 返回第一组 → 确认七电机失能并退出。失能后电机不再保持位置，最后的“已失能”反馈不应当成仍保持第一组姿态的证明。每次修改参数前，上一轮控制器已退出并释放 CAN。

先用 0–10°、单程 12 秒建立小范围基线，再用 0–30°、单程 12 秒比较增益。每次只改 J2 `KP_APR`，写 RAM 并读回，不保存 Flash。初始 [24 项参数快照](../../validation/j2_tuning/20261009_122705/initial_parameters.json) 中：`KP_APR=54`、`KI_APR=0`、`KP_ASR≈0.00384`、`KI_ASR≈0.002`，`ACC=2`、`DEC=-2`、`MAX_SPD=600`。

评价目标：完整往返计划—实测最大误差 ≤2°，保持最后 1 秒位置跨度 ≤0.2°，平均保持误差 ≤0.2°，端点超越 ≤0.3°，正常结束并确认失能。这些是本轮试验标准，不是厂商额定指标。不同角度窗口用于检查重力负载变化，不能代表所有 J3–J6 姿态或负载已经验证。

## 一次中断及复测

首次 70–100°试验的快速往返和两个端点保持已经完成，随后缓慢回零到约 68°时出现 `controller feedback expired`。记录中控制器状态相隔约 **64 ms**，超过实验 50 ms 门限；随后记录到参考超时停止，程序确认七电机失能。这一轮整体记为失败，不能仅凭前段 1.959°的误差把它记成完整通过。

独立只读检查确认七电机静止、失能、无故障码，操作者确认“已稳定，没有异常，可继续”。复测只增加接收时间戳和中止快照，**没有修改增益或超时门限**。复测完整完成去程、回程、回零与失能，最大误差 1.955°；已记录状态最大间隔 39.88 ms，接收时状态最大年龄 7.58 ms。

目前证据只能确认一次状态流中断，尚不能区分发布、接收或主机调度原因；不能宣称已定位或彻底修复这次偶发中断。细节见 [中断记录](../../validation/j2_tuning/20261009_122705/interruption_70to100.json)、[失败轮报告](../../validation/j2_tuning/20261009_122705/real_kp250_70to100deg_6s/report.json)与[复测时序统计](../../validation/j2_tuning/20261009_122705/repeat_timing_summary.json)。

## 参数应用与适用范围

[最终 24 项快照](../../validation/j2_tuning/20261009_122705/final_parameters.json)与[选择记录](../../validation/j2_tuning/20261009_122705/selection.json)确认只改变 `KP_APR: 54 → 250`；`KI_APR=0`、`KP_ASR≈0.00384`、`KI_ASR≈0.002`、`ACC=2`、`DEC=-2`、`MAX_SPD=600` 均保持初值。250 是本轮满足目标的已测选值，没有继续寻找极限增益。

已验证的是当前负载、J1/J3–J6 固定为本文第一组姿态、J2 在 0–103.19°范围、最高计划峰值 9.375°/s。覆盖了随 J2 角度变化的部分重力负载，**不等于其他整臂姿态、负载或更高速度都已验证**。J3–J6 的位置环尚未在本轮调参。

当前供电不中断时，J2 已处于本轮 RAM 值，无需重复写入或重新编译。重新上电后先读回，需要恢复本轮值再临时写入；所有命令都在退出占用 CAN 的程序后执行：

```bash
source scripts/environment.bash
a6y_load_install
ros2 run a6_y_ros2_control read_motor_params.py --joints joint2 \
  --params KP_APR,KI_APR,KP_ASR,KI_ASR,ACC,DEC,MAX_SPD

# 恢复本轮 J2 试调值，仅 RAM
ros2 run a6_y_ros2_control write_motor_params_temp.py --joints joint2 --set KP_APR=250 --yes

# 回退本轮初始值，仅 RAM
ros2 run a6_y_ros2_control write_motor_params_temp.py --joints joint2 --set KP_APR=54 --yes
```

本轮未发送 Flash 保存帧，未验证掉电保持。[最终独立只读记录](../../validation/j2_tuning/20261009_122705/final_readonly_status.jsonl)对七电机各收到 123 帧，均为失能；J2 MOS/线圈温度为 30/29°C。温度字段按上述手册第 7 页解析。失能后电机不保持第一组姿态，最终只读 J2 约 -0.16°、J3 约 0.32°。CAN 释放和无残留控制进程见[结束进程状态](../../validation/j2_tuning/20261009_122705/final_process_status.json)。
