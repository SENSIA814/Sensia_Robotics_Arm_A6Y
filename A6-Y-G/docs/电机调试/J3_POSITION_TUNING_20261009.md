## 调参前修正：J3 速度反馈量程

[初始 24 项参数快照](../../validation/j3_tuning/20261009_130420/initial_parameters.json)发现 J3 的 `VMAX=20`，而原驱动对 `DM4340P` 默认按 10 解码。同一反馈位模式下，旧解码速度只有按实读量程解码结果的一半；位置和力矩量程一致，不受影响。这是协议量程与配置不匹配，不能靠增加位置增益纠正。

本轮给 C++ 驱动、只读扫描/采样工具增加逐电机 `protocol_vmax`，三份 A5 电机 YAML 仅为 J3 填入实读值 20，xacro 将该字段传递到硬件插件。J1/J2 仍沿用各自默认 10。字段只规定协议速度数值的编码/解码范围，**不是控制速度上限**；没有写电机 `VMAX`，没有提高任何关节的指令限速。

修复后的小角度实机记录中，在有效运动样本上，报告速度与编码器 200 ms 差分速度的比值中位数约 0.985，支持量程匹配。见 [量程验证](../../validation/j3_tuning/20261009_130420/protocol_vmax_verification.json)。C++ 协议检查验证速度倍数关系及位置/力矩不变；Python 检查验证 J3 覆盖不会改变同型号 J1，拒绝非有限、零和负量程。

## 测试方法

专用 [J3 测试脚本](../../tools/test_j3_position.py) 使用 `/j3_test` 控制器，125 Hz，原生 `pos_vel`，真实域 0、模拟域 88。无 VR 或逆运动学输入。六轴保持，夹爪只读。保留 0.05 rad 跟踪误差门限、跟踪减速器、1 rad/s 指令速度上限、3 rad/s²参考加速度、反馈与通信超时，并按项目已有六轴反馈力矩上限 10/20/20/3/4/4 N·m 检查。

每轮流程为：当前位置捕获保持 → 回初始姿态 → J3 测试窗口起点 → J3 去程、保持、回程、保持 → 回初始姿态 → 七电机失能、退出并释放 CAN。失能后电机不再保持姿态。轨迹为端点速度/加速度均为零的五次曲线。完整遥测直接写 JSONL，分析与绘图在停止电机后进行，避免控制阶段积累完整遥测对象。

先做 10°/12 秒基线，再用相对 30°/12 秒比较增益；需要时用 30°/6 秒验证提速。每次只修改 J3 `KP_APR`，写 RAM 后读回，不保存 Flash。判据：完整往返计划—编码器最大误差 ≤2°，保持最后 1 秒跨度 ≤0.2°、平均误差 ≤0.2°、端点超越 ≤0.3°，完整完成并确认失能。这是本轮目标，不是厂商额定精度。

## 参数应用与适用范围

[最终 24 项快照](../../validation/j3_tuning/20261009_130420/final_parameters.json)与[选值记录](../../validation/j3_tuning/20261009_130420/selection.json)确认仅 `KP_APR: 54 → 250`；`KI_APR=0`、`KP_ASR≈0.00384`、`KI_ASR≈0.002`、`ACC=2`、`DEC=-2`、`MAX_SPD=600`、`VMAX=20` 均保持初值。这里调整的是电机原生位置环，不是 ROS 阻抗控制器的 `kp`。

已验证范围为当前负载、本文 J1/J2/J4–J6 固定姿态、J3 约 0.32–87.30°，最高计划峰值 9.375°/s。不同 J3 角度覆盖了部分重力负载变化，**不等于其他整臂姿态、负载或更高速度都已经验证**。

当前未断电时已经使用 250，无需重复写入。参数临时写入不需要编译；本轮涉及速度反馈量程的 C++ 驱动改动已完成编译安装。退出占用 CAN 的程序后，可用以下命令读回、恢复或回退：

```bash
source scripts/environment.bash
a6y_load_install
ros2 run a6_y_ros2_control read_motor_params.py --joints joint3 \
  --params KP_APR,KI_APR,KP_ASR,KI_ASR,ACC,DEC,MAX_SPD,VMAX

# 恢复本轮 J3 试调值，仅 RAM
ros2 run a6_y_ros2_control write_motor_params_temp.py --joints joint3 --set KP_APR=250 --yes

# 回退本轮初始值，仅 RAM
ros2 run a6_y_ros2_control write_motor_params_temp.py --joints joint3 --set KP_APR=54 --yes
```

[最终独立只读采样](../../validation/j3_tuning/20261009_130420/final_readonly_status.jsonl)对七电机各收到 125 帧，全部为失能状态；J3 MOS/线圈温度为 31/29°C。温度按[厂商手册反馈字节定义](https://doc.switch-science.com/media/files/5e033168-99f1-4d2d-b758-e03192a1f071.pdf)解析。最终原始 J3 约 0.00515 rad（0.295°）。失能后电机不再主动保持姿态。串口与进程检查见 [结束状态](../../validation/j3_tuning/20261009_130420/final_process_status.json)。
