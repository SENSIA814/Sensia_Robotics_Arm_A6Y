## 速度含义与测试范围

这里的 90°/s 是平滑轨迹的**峰值速度**。五次曲线从静止加速、再减速到静止，90°单程时间为 1.875 s，计划峰值加速度约 2.58 rad/s²；不是从起点立刻以 90°/s 匀速转满 1 秒。

操作者确认以当前实际位置为起点，沿此前相同方向转动 90°再返回，整个扫掠范围无碰撞、现场无人进入且可就地断电。模型坐标下，J1 起点约 −1.104°，终点约 +88.896°；J1 电机原始坐标方向与模型相反。起点与授权记录保存在 [operator_anchor.json](../../validation/j1_highspeed/20261009_90dps/operator_anchor.json)。

六个机械臂关节均采用原生位置速度模式：J1 运动，其余五轴保持；夹爪始终只读、失能。本次没有使用 Quest、IK 或力控。J2 初始读数 −0.004005 rad 在已有零位容差内，保持目标取名义零位，约向内修正 0.23°；没有修改零点 offset。

这个结果仅覆盖本次姿态、负载、行程和轨迹，不能代表 J2–J6 或整臂 VR 已完成 90°/s 验证。

## 判定方法与实测结果

试验前记录的[判定标准](../../validation/j1_highspeed/20261009_90dps/protocol.json)为：完整往返并失能；实测峰值处于计划峰值的 95%–105%；最大计划轨迹误差 ≤3°；两端保持最后 1 秒的位置跨度及平均误差绝对值均 ≤0.2°；端点超越 ≤0.5°。这些是本次试验标准，不是厂商额定指标。

## 中途问题与处理

1. 首次增益 250、20°/s 试验在 ARM 阶段被拒绝，尚未开始扫掠。保持准备后手腕关节仍有微小调整；脚本补充“六轴稳定后再 ARM”的等待，没有放宽稳定门限。重试完成。
2. 增益 1600、75°/s 试验在去程中触发 `TRACKING_ERROR`，没有完成往返。当时通信时序正常，J1 跟踪误差接近 0.05 rad 门限；记录到停止前误差约 2.86°。已确认全部失能，操作者确认现场无异常，并**手动回到起点**。这轮不得作为完整速度验证。
3. 保留原误差门限，将增益逐级提高到 2000 后通过 75°/s；再在相同 75°/s 下验证 2500，为 90°/s 留出误差余量，随后两轮 90°/s 均通过。没有修改速度环增益、原生加减速或电流参数。

原生位置速度模式使用内部位置、速度、电流串级环，`v_des` 表示最大绝对速度；`KP_APR` 是原生位置环寄存器，不能与 MIT 指令的 Kp 字段混用。接口语义参考[达妙 DM-J4340P-2EC 官方说明](https://damiao.enactic.ai/en/products/hardware/dm-j4340p-2ec-v1.0/)。本次实际改善由逐轮实测支持，不由参数数值单独推断。

## 读取、应用与回退

退出占用 CAN 的程序后读取：

```bash
cd /home/alce/Code/A6-Y-G
source scripts/environment.bash
a6y_load_install
ros2 run a6_y_ros2_control read_motor_params.py --joints joint1 \
  --params KP_APR,KI_APR,KP_ASR,KI_ASR,ACC,DEC,MAX_SPD
```

电机重新上电后应先读回；需要恢复本轮参数时，确认电机失能，再临时写入。回退值为**本轮开始时的 250**，不是更早的初始 54：

```bash
# 本轮选值，只写 RAM
ros2 run a6_y_ros2_control write_motor_params_temp.py --joints joint1 --set KP_APR=2500 --yes

# 回退至本轮开始前
ros2 run a6_y_ros2_control write_motor_params_temp.py --joints joint1 --set KP_APR=250 --yes
```

以上改参数不需要重新编译。没有发送 Flash 保存帧；掉电后按电机已有 Flash 内容加载。保存语义见 [MOTOR_PARAMETERS.md](MOTOR_PARAMETERS.md)。

在本次确认过的初始姿态和扫掠范围内复测：

```bash
bash scripts/run_j1_highspeed_test.bash --mode real \
  --anchor-json validation/j1_highspeed/20261009_90dps/operator_anchor.json \
  --degrees 90 --peak-speed-deg-s 90
```

该命令使用本次保存的起点，不会把任意新姿态自动当作起点；正常测试要求当前六轴与保存姿态相差不超过 2°。`--return-home-only` 是单独的低速回位分支，只允许 J1 位于已确认扫掠范围内、其他轴仍接近保存姿态，回位峰值不超过 2.5°/s；本次仅做了该分支的 mock 验证，实机故障后的回位由操作者手动完成。

离线统计与曲线重建：

```bash
source scripts/environment.bash
python3 tools/analyze_j1_highspeed.py validation/j1_highspeed/20261009_90dps --plot
```
