## 调参过程与实测结果

先以 `KP_APR=1250` 做 10°、5°/s 小范围试验，再扩大到 85°行程，分档提速；同一速度下比较不同位置增益。位置增益依次试到 1600、2000、2500。

`KP_APR=1600` 的 75°/s 试验在去程中途触发跟踪误差停止，`state=4, reason=11`，未完成往返。最后有效样本的计划—实际误差约 2.86°，停止记录中的 J3 约 36°；没有电机故障或通信超时证据。七电机确认失能后，操作者反馈“已稳定，没有异常，可以继续”，独立只读采样确认 J3 已在起点附近且静止。随后提高位置增益重新验证，没有放宽跟踪门限。

`KP_APR=2500`、原速度环的首轮 90°/s 已达到速度和误差目标，但操作者报告“有一点点抖动”，因此没有选为最终结果。随后保持位置增益和积分项，只把 `KP_ASR` 从 0.00384 提到 0.004608；75°/s 验证后，两轮 90°/s 均完成，且得到现场平稳反馈。

## 速度环调整的效果

同为 `KP_APR=2500`、90°/s、85°行程，到达高位后前 1.5 s 的对照：

| 指标 | 原速度比例 | 提高 20%，第一轮 | 提高 20%，重复轮 |

| 保持中的 J4 角度峰峰值 | 0.415° | 0.197° | 0.350° |
| 现场反馈 | 有一点点抖动 | 已平稳，无明显抖动或异响 | 仍平稳，无明显抖动或异响 |

![到位后速度环对照](../../validation/j3_highspeed/20261009_90dps/speed_loop_comparison_90dps.png)

数据支持本轮速度环调整改善了 J3 的到位过程；J4 仍有小幅偏摆，不能描述为全臂完全没有振动，也没有据此改动 J4 参数。实际改动的是原生速度环 `KP_ASR`，`KI_ASR`、`Deta` 和 MIT 模式 `kd` 均未修改。

最终两轮去程峰值分别为 89.747、89.779°/s，回程分别为 **89.443、89.385°/s**，两方向均达到目标 ±5% 判据。不能仅用较快的单方向峰值代替往返验证。

两轮最大“已下发参考—编码器”误差为 2.676°、2.663°，低于保留的 0.05 rad 跟踪门限；跟踪减速占比均为 0。J3 测试窗口力矩绝对峰值分别为 9.634、9.730 N·m。保持最后 1 s 的 J3 位置跨度均不超过 0.022°，平均保持误差绝对值不超过 0.021°，端点超越不超过 0.022°。编码器一格约 0.022°，小跨度不能解释为无限精度。

## 读回、恢复和复测命令

临时参数写入和直接运行这些 Python/Bash 工具无需重新编译。已读回确认当前 RAM 是最终选值；掉电后应重新读取，不能假定 RAM 调参结果仍在。读写参数前先退出占用 CAN 的控制程序。

```bash
cd /home/alce/Code/A6-Y-G
source scripts/environment.bash
a6y_load_install

# 只读核对 J3
ros2 run a6_y_ros2_control read_motor_params.py --joints joint3 \
  --params CTRL_MODE,KP_APR,KI_APR,KP_ASR,KI_ASR,VMAX

# 恢复本轮最终选值，仅 RAM；不会使能或保存 Flash
ros2 run a6_y_ros2_control write_motor_params_temp.py --joints joint3 \
  --set KP_APR=2500 --set KP_ASR=0.004608 \
  --set KI_APR=0 --set KI_ASR=0.002 --yes

# 回退本轮开始时的低速参数，仅 RAM
ros2 run a6_y_ros2_control write_motor_params_temp.py --joints joint3 \
  --set KP_APR=250 --set KP_ASR=0.00384 \
  --set KI_APR=0 --set KI_ASR=0.002 --yes
```
