二、目录与内容

src/A5/：A5 URDF、9 个 STL 网格、CAD 参数及模型约定；ROS 包名为 a5_description。
src/a6_y_ros2_control/：电机通信、ros2_control 硬件驱动、ID 设置及参数读写工具。
src/a6_y_controllers/：重力补偿、笛卡尔阻抗、关节阻抗、原生位置控制相关配置与测试。
src/a6_y_teleop_msgs/：VR 控制消息。
src/a6_y_vr_teleop/：VR 映射、逆运动学、虚拟/实机桥接、标定及测试。
vr_gateway/：Quest/Vuer 网关、依赖声明、锁定版本和第三方说明。
scripts/：环境、启动、证书生成及实验入口。
tools/：模型验证、标定、调参、诊断、回放和结果分析工具。
docs/：使用说明、设计、调参记录、验证边界和图片。
validation/：模型检查、测试报告、参数快照、实机原始采样、故障诊断和回放数据。

保留 validation 中的 JSONL、CSV、测试日志和历史快照，便于接手者复核调参结论及故障。该目录约 4.62 GiB，是压缩包主要体积来源。validation 下名称含 backup 的目录及 sources 子目录都是历史备份/证据，不是当前源码入口；开发以根目录 src/、scripts/、tools/ 为准。

三、新机器恢复

目标运行环境来自项目说明：Ubuntu 22.04、ROS 2 Humble、ros2_control、Pinocchio >= 4.0。CMake 明确要求 Pinocchio 4.0；若软件源版本较低，须先解决版本依赖。依赖安装命令详见 README.md。

将 A6-Y-G/ 解压至新的 Linux 工作目录，以下命令都在该目录执行。文档里的 /home/alce/Code/A6-Y-G 和历史局域网 IP 是原机器环境，请替换为实际位置和地址。

首次构建全部源码：
  source scripts/environment.bash
  export MAKEFLAGS='-j2 -l2'
  colcon build --base-paths src --symlink-install --executor sequential --cmake-args -DCMAKE_BUILD_TYPE=Release
  a6y_load_install

根目录保留 COLCON_IGNORE，构建必须显式带 --base-paths src。内存不足时按 README 将 MAKEFLAGS 降为 '-j1 -l1'。
本包不含旧机器的 build/、install/，因此文档中“已构建/已安装”的描述属于历史状态，新机器必须重新构建。
ZIP 记录了脚本可执行位；如果解压工具不恢复权限，Bash 入口可通过 bash scripts/xxx.bash 执行。

先进行无硬件检查（完整列表与判定边界见 docs/标定与验证/VALIDATION.md）：
  source scripts/environment.bash
  a6y_load_install
  export ROS_DOMAIN_ID=193 ROS_LOCALHOST_ONLY=1
  export ROS_LOG_DIR="$PWD/validation/ros_logs"
  mkdir -p "$ROS_LOG_DIR"
  ctest --test-dir build/a6_y_ros2_control --output-on-failure
  ctest --test-dir build/a6_y_controllers --output-on-failure
  /usr/bin/python3 tools/validate_bundle.py
  /usr/bin/python3 tools/test_s0.py
  /usr/bin/python3 tools/verify_s0.py
  /usr/bin/python3 tools/verify_dry_run.py

无硬件 RViz 示例：
  ros2 launch a6_y_controllers a5_gravity_comp.launch.py dry_run:=true auto_enable:=false use_rviz:=true

这些验证脚本可能更新 validation 下同名报告；需要比较历史证据时，先留存原压缩包，在另一份解压目录运行。

VR 网关环境需要重建：
  python3 -m venv .venv-vr
  .venv-vr/bin/python -m pip install -r vr_gateway/requirements.lock

系统需提供 Python venv 和 OpenSSL。旧主机的 TLS 证书/私钥未打包，按新主机局域网 IPv4 重新生成：
  bash scripts/create_vr_certificate.bash <新主机局域网IPv4地址>

虚拟 VR 入口为 scripts/run_vr_rviz.bash；网关为 scripts/run_vr_gateway.bash。端口、Quest 浏览器、证书信任、录制与回放详见 docs/VR遥操作/虚拟机械臂/VR_RVIZ_USAGE.md。
实机模式和完整原生位控另有专用入口，按 docs/VR遥操作/实机控制/VR_REAL_ROBOT_USAGE.md 操作。

  J1     2500     0.00384     0.002

以上四轴当次 KI_APR=0、ACC/DEC=2/-2、CTRL_MODE=2。精确值和原始寄存器位模式以 JSON 快照为准。

当次 J1～J4 保存应答和保存前后读回一致，但尚未完成电机电源断电重启后的保持验证。接手后先只读核对，再考虑参数写入或运动。J5、J6、夹爪未参加该次 Flash 保存。

J4 在 40°/s 规划下有现场平稳反馈；该结论不等于全部数值指标通过，更不代表 90°/s 已验收。最新文档记录回程峰值仍略超此前 ±5% 条件；历史试验没有增益快照，不能把最新参数倒推为历史试验已核实的参数。
