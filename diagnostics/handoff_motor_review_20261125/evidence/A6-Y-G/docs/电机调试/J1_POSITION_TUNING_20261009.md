## 测试方法

操作者授权 J1 在当前安装位置转动 30°，说明周围无人，并在早期与提速后分别确认“运动平稳，没有异常”。专用脚本只使能 J1，其余六电机只读；每轮从实时反馈捕获起点，沿五次平滑轨迹相对 +30°，到位保持，再返回起点并保持，最后失能。未使用 Quest、逆运动学或重力/阻抗控制。

初始及各候选的控制器参数逐项一致：125 Hz；位置模式速度上限 1 rad/s；参考加速度上限 3 rad/s²；硬跟踪误差门限 0.05 rad；保留跟踪减速器。测试轨迹实际计划峰值低于这些上限：12 秒轨迹为 4.6875°/s，6 秒轨迹为 9.375°/s。

每次只修改 `KP_APR`，由独立工具写 RAM、读回确认后再开始运动。增益依次为 `54 → 60 → 72 → 90 → 108 → 135 → 168 → 210 → 250`。原生位置速度模式的 `v_des` 是速度上限，内部位置环仍决定误差如何转化为速度要求；该模式的三环结构见[达妙 DM-J4340P-2EC 说明书，第 5–6 页](https://doc.switch-science.com/media/files/5e033168-99f1-4d2d-b758-e03192a1f071.pdf)。

本轮比较目标为：完整往返的计划—实际最大误差 ≤2°；超越端点 ≤0.3°；每个保持阶段最后 1 秒的位置跨度 ≤0.2°；返回误差 ≤0.2°；正常结束并确认失能。这些是本轮试验标准，不是厂商额定指标。先用 12 秒轨迹建立对照，再用 6 秒轨迹检查提速后是否仍满足目标。

## 结论与适用范围

J1 在本轮安装姿态下慢跟随的主要原因是原生位置环对位置误差的响应偏慢，随后触发上层跟踪减速；提高 `KP_APR` 在不放宽上层限制的情况下消除了减速。相同 12 秒轨迹的最大误差由 7.682°降到 0.943°，下降约 87.7%；运动段 RMS 误差由 4.591°降到 0.571°。本轮不需要再修改速度环、加减速或速度上限。

最终 250 的两次快轨迹均满足预设目标。实测端点超越约 0.010°，小于一格编码器分辨率；返回误差为 0–0.022°。同条件 12 秒测试的反馈力矩峰值由约 1.224 N·m 变为 1.333 N·m，RMS 由 0.492 变为 0.485 N·m；两次快轨迹峰值均约 1.210 N·m。这里是电机反馈量，不是经外部力矩传感器校验的测量。

250 是本轮已测试参数中满足快慢两组跟踪目标的选择；没有继续寻找极限增益。测试范围是当前姿态/负载、30°相对往返、最高计划峰值 9.375°/s，不能据此认定所有姿态、负载或更高速都已验证，也不能将 J1 的参数直接复制到 J2–J6。整臂 VR 的动态效果尚需分别验证其他关节。

## 应用与恢复

该次低速试验结束时 J1 为 `KP_APR=250`；后续高速试验已更改为 2500，当前值应读回确认。退出占用 CAN 的控制程序后可只读核对：

```bash
source scripts/environment.bash
a6y_load_install
ros2 run a6_y_ros2_control read_motor_params.py --joints joint1 \
  --params KP_APR,KI_APR,KP_ASR,KI_ASR,ACC,DEC,MAX_SPD
```

电机重新上电后，如需恢复本轮试调值，先核对再临时写入；需要回退则写 54：

```bash
# 应用本轮 J1 候选值，不保存 Flash
ros2 run a6_y_ros2_control write_motor_params_temp.py --joints joint1 --set KP_APR=250 --yes

# 回退本轮开始前的 J1 值
ros2 run a6_y_ros2_control write_motor_params_temp.py --joints joint1 --set KP_APR=54 --yes
```

永久保存的命令及“保存整个 RAM 参数集”的语义见 [MOTOR_PARAMETERS.md](MOTOR_PARAMETERS.md#3-将已验证的参数保存到-flash)。本轮未发送 Flash 保存帧，也未验证掉电后的保持。
